# Three-minute TeachMate demonstration

Use only the synthetic seeded class. Start the app according to the README and sign in with the demo teacher account.

**0:00–0:25 — The work awaiting you**

Open the dashboard. Point out the actual Grade 8A English class and the stored reading assessment. The dashboard counts come from saved assessments and submissions. Explain that **Demo mode** is visibly labelled and uses deterministic simulated marking; live mode uses the configured server-side model.

**0:25–0:55 — Give TeachMate a goal**

Open the new-assessment form or the seeded draft. Inspect the goal, the passage and question, the three-criterion rubric (4 + 4 + 2 marks), and the learner responses. The seeded dataset includes a confirmed blank response and an ambiguous interpretation. Use the validation preview before creating a new assessment. A duplicate upload is identified rather than producing a second gradebook row.

**0:55–1:35 — Watch actual work happen**

Start the run and open the agent workspace. Show the structured plan, task checklist and saved activity feed as the backend extracts, validates, assesses and reviews the supplied material. The six stages are Goal, Plan, Act, Check, Correct and Deliver. With the labelled fault-injection option enabled, show the explicit injected incorrect-total event, the review that catches it, and the correction that recalculates it. Explain that this error was deliberately injected for the demonstration.

**1:35–2:15 — Exercise teacher judgement**

Open the review desk. Compare a learner's original answer with criterion marks, exact supporting evidence and concise feedback. Change a criterion mark or feedback and save the teacher edit; the total and report update and the edit is versioned. Open the ambiguous response to inspect its blocking flag. Resolve a judgement issue only after entering a reason. Unreadable and missing responses require replacement input and never become automatic zero marks. Approve one result or the eligible batch.

**2:15–2:40 — Deliver completed work**

Open the reports and gradebook. Draft, approved and published rows have distinct statuses. Show the distribution and criterion averages and explain that observed difficulties do not establish a diagnosis. Download the CSV and open the printable report. Exports include only approved or published results and match their stored marks. Publish approved feedback inside TeachMate.

**2:40–3:00 — Check the learner boundary**

Sign out and sign in as one synthetic learner. Show only that learner's published feedback, rubric marks and result. Draft feedback and classmates' results are unavailable. Close by showing how to delete the assessment with its uploaded files and generated outputs.

For a live demonstration, configure the provider credentials first and explicitly select **Live mode** when creating an assessment. Do not describe simulated demo results as live AI output.
